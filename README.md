# MAISON — приложение для Маркетплейс Битрикс24

Тиражное приложение: при установке на портал клиента автоматически создаёт
готовый интернет-магазин женской одежды.

## Что создаётся при установке

- **Сайт-витрина** (тип STORE) с 10 страницами: главная, каталог,
  карточка товара, новинки, о бренде, контакты (со штатной CRM-формой),
  доставка, возврат, FAQ, политика конфиденциальности.
- **18 премиум-блоков конструктора** (`vl-maison-*`) — фирменный стиль
  MAISON: чёрно-белая гамма, Playfair Display + Montserrat.
- **Демо-каталог**: 6 разделов, 30 товаров, торговые предложения
  по цвету и размеру.
- Корзина, оформление заказа и личный кабинет работают штатно
  через магазин Битрикс24.

## Структура

```
app/
  server.js   — сервер установки (OAuth, провижининг, uninstall)
  pages.js    — карта страниц (массивы блоков снизу вверх!)
  blocks/     — 18 определений блоков для landing.repo.register
  assets/     — css/js/картинки блоков (раздаются через jsDelivr)
tools/
  gen-blocks.js — генератор blocks/*.json из проверенных payload
prototype-pages/ — HTML-прототипы дизайна (справочно)
```

## Конфигурация

Скопируйте `config.example.json` в `app/config.json` или задайте переменные
окружения:

| Переменная | Назначение |
|---|---|
| `MAISON_CLIENT_ID` | client_id из кабинета партнёра |
| `MAISON_CLIENT_SECRET` | client_secret из кабинета партнёра |
| `APP_URL` | публичный адрес сервера приложения |
| `PORT` | порт (по умолчанию 3000) |

## Обработчики для кабинета партнёра

- URL обработчика установки: `https://<APP_URL>/install`
- Ссылка на приложение: `https://<APP_URL>/app`
- Права (scope): `landing, catalog, sale, user_brief`

## Запуск локально

```
npm start
```

Проверка жизни: `GET /status` → `{"ok":true,"app":"maison"}`
